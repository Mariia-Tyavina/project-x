# 🎬 Кинопоиск по настроению

Веб-приложение для управления фильмами и цветами с семантическим поиском и визуальным интерфейсом.

Главная страница

## 🌟 Возможности

- **Каталог фильмов**  
  – Добавление вручную или автоматически через TMDB (постер, режиссёр, жанры → теги)  
  – Отображение постеров  
  – Поиск по тегам (с режимом «все теги»)  
  – Семантический поиск по описанию (через FAISS и Sentence-Transformers)

- **Каталог цветов**  
  – Добавление цвета с тегами (например, «зеленый» → «природа, спокойствие»)  
  – Поиск цветов по тегам  
  – Клик по цвету → поиск фильмов с этими тегами (связь через теги)

- **Дизайн**  
  – Тёмная тема с анимированным звёздным небом  
  – Единый стиль кнопок, форм и карточек


## 📦 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/Mariia-Tyavina/project-x
```


### 2. Установите зависимости
В терминале запустите команду:
```bash
pip install flask requests python-dotenv numpy faiss-cpu sentence-transformers
```

### 3. Установите vpn
Если вы в России, для доступа к TMDB может потребоваться VPN или прокси – это связано с ограничениями самого сервиса.


### 4. Настройте API-ключ TMDB
Зарегистрируйтесь на themoviedb.org
Получите API-ключ v3 auth в настройках аккаунта.
В корне проекта создайте файл .env (этот файл не должен попасть в Git!).
Внутри файла напишите данное выражение, где вместо названия "ваш ключ" вы должны вписать ваш API ключ.
```bash
TMDB_API=ваш_ключ
```


### 5. Запустите приложение
В терминале запустите команду:
```bash
python app.py
```


### 6.После запуска сервер будет доступен по адресу:
```bash
http://127.0.0.1:5000
```
